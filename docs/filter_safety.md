# 过滤模块安全失效设计（filter_safety）

> 安全场景的第一原则：**宁可吵，不可聋。**

## 一、失效模式清单（FMEA）

| # | 失效模式 | 触发条件 | 后果 | 严重度 | 处置 |
|:--:|---|---|---|:--:|---|
| F1 | 白名单被误抑制 | AED 把 siren 判成 air_conditioner | 用户听不到警报 | **致命** | 硬门校验 + fail-open + 触觉兜底 |
| F2 | 过抑制（整体音量塌陷） | TSE 模型分布外输入 | 听觉环境突然变"空"，危险感丧失 | 高 | 输出能量下限监测（见 §二.2） |
| F3 | 增益跳变（呼吸/抽气声） | 逐窗归一化、硬 top-1 切换 | 不适、被误认为设备故障 | 中 | 跨帧平滑 + softmax 软混合 |
| F4 | 处理超时 / 队列积压 | CPU 争用、GC 停顿 | 音频卡顿、延迟暴涨 | 中 | 超时即直通（drop filter, keep audio） |
| F5 | 数值异常 | NaN/Inf 掩码 | 输出静音 | **致命** | NaN 检测 → 立即切硬旁路 |
| F6 | 用户误配置 | 把 siren 放进黑名单 | 主动屏蔽警报 | **致命** | UI 禁止 + 服务端校验 |
| F7 | 端侧 OOM | 模型/缓冲区过大 | 重启循环 | 低 | 参数上限 + 预分配缓冲 |

## 二、三层防护（不可绕过）

### 2.1 第 1 层：硬门校验（Hard Gate）

对每个输出 chunk：

```
若 存在 c ∈ WHITELIST 使 p_t(c) > 0.5：
    Pres_dB(c) = 10·log10( ‖y_out 中该类频段能量‖ / ‖y_in 中同类频段能量‖ )
    若 Pres_dB < −3 dB → 该 chunk 输出 = 输入（直通），并计数 silent_suppression_events
```

- 实现：用 AED 后验加权该类的平均 Mel 谱 `A_c(f)` 作为频段权重，计算进出口频段能量比。
- **计数必须上报**：`silent_suppression_events > 0` 即视为版本缺陷（哪怕被兜底救回）。

### 2.2 第 2 层：能量下限监测（Anti-Collapse）

```
若 10·log10( ‖y_out‖² / ‖y_in‖² ) < −20 dB（整体能量塌陷超过 20 dB）
   → 判定为过抑制 → 直通 + 记录 over_suppression_events
```

理由：真实环境不存在"全频段安静 20 dB"的合法场景；出现即模型失效。

### 2.3 第 3 层：fail-open（默认直通）

以下任一条件成立即直通，且**不做重试**：

| 条件 | 阈值 |
|---|---|
| AED 置信度低 | `max_c p_t(c) < 0.4` |
| 推理超时 | 单 chunk > 10 ms（CPU 计时） |
| 队列积压 | backlog > 2 chunk |
| 数值异常 | 掩码含 NaN/Inf 或全零 |
| 冷启动 | 上电后前 200 ms |
| 用户硬旁路 | 物理/软件开关 |

fail-open 是**设计特性而非缺陷**，报告里要单列次数（说明系统活跃度）。

## 三、用户配置校验（F6）

```
校验规则：
1. WHITELIST 四类（siren, car_horn, gun_shot, dog_bark）不可移入 blacklist；
2. 若用户坚持 → 返回 400 + 提示文案，同时把 profile 降级为 "comfort_only"：
   该档位下所有抑制量再减半（最多 −6 dB），并在 UI 常驻提示"已关闭安全保护"；
3. neutral（children_playing）可自由移动；
4. 单类抑制上限 −24 dB，总抑制上限 −30 dB（硬编码，不可配置）。
```

## 四、降级矩阵（硬件/算力不足时）

| 可用资源 | 模式 | 行为 |
|---|---|---|
| 算力充足 + 权重完整 | C 混合 | B 为主，A 兜底 |
| 无 TSE 权重 | A 单方案 | 谱增益门，抑制 ~12 dB |
| 仅能跑 AED（如 MCU 满载） | **门控级**（仅当检测层达标才允许） | 黑名单窗整段衰减，白名单窗直通 |
| AED 也不可用 | **直通 + 触觉** | 完全依赖 A4 触觉通道，最安全的降级 |

> 注意：门控级（整窗衰减）是**最激进的模式**，其安全性完全依赖于检测层召回率。当前检测层 83.3% 不达标 → **该模式默认禁用**，代码中以 `allow_gating=False` 强制关闭。

## 五、伦理与合规

1. **不可宣称医疗功效**：本项目为辅助感知工具，非助听器/医疗器械；报告与 demo 均须声明。
2. **用户知情**：任何过滤档位切换必须在 UI 明示（"当前正在抑制：空调、街边音乐"）。
3. **不做隐蔽录音**：双麦输入仅用于本地推理，不落盘、不上传。
4. **主观测试伦理**：≥5 人 AB 测试须签署知情同意（用途、时长、可随时退出），听障/PTSD 参与者提供退出机制；素材不含真实枪声（用 ESC-50 fireworks 替代）。
5. **数据许可**：UrbanSound8K (CC BY-NC)、ESC-50 (CC BY-NC)、FSD50K (CC BY) — 学术使用，报告注明。
